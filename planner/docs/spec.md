# 풍류천재 기획안 자동 완성 프로그램 — 개발 핸드오프 (원본 스펙)

채팅(프로젝트 "기획안 작업")에서 손으로 하던 기획안 작성을 프로그램으로 자동화하기 위한 정리.

## 1. 배경 — 지금까지 채팅에서 한 작업

* 채널: 풍류천재조서형 (출연: 조서형 셰프 / 담당 PD: 정해빈)
* 코너: 치트키(요리 레시피), 풍류유람기(지역 맛집 투어), 마감주(요리 + 안주 먹방) — 이 3개
* 작업 방식: 이전 기획안 PDF(레퍼런스) + 이번 회차 메뉴/주제 한 줄 → 레퍼런스와 같은 구성으로 모든 항목을 채운 새 기획안
* 실제 사례 (2026-11-20): 치트키 김장 편(배추김치·총각김치·오징어 석박지·수육, 18페이지) 기획안을 레퍼런스로 → 치트키 "소고기 장조림 & 경상도식 소고기무국" 편 기획안 작성
* 주의: 레퍼런스 PDF에 텍스트 레이어가 없었음(이미지형) → `pdftotext` 실패, 페이지를 이미지로 렌더링해서 읽어야 했음. 프로그램도 이미지/비전 입력 또는 OCR 경로가 필요함.

## 2. 입력 / 출력

입력
* 레퍼런스 기획안 (PDF, 이미지형일 수 있음) — 선택. 없으면 기본 템플릿 사용
* 코너명 (예: 치트키)
* 이번 회차 메뉴/주제 (예: 소고기 장조림, 경상도식 소고기무국)
* 선택 입력: 촬영 날짜, 콜타임, 장소, 촬영감독, 발행일, 주차 안내, 제작 일정

출력
* 템플릿의 모든 섹션이 채워진 기획안 (Markdown → 이후 Docs/PDF/Notion 등으로 변환)
* 맨 끝에 "비워 둔 항목" 목록과 "셰프님 확인이 필요한 부분" 목록

## 3. 작성 규칙 (중요)

* 모르는 값은 지어내지 말고 `⬜ 미정` 으로 표시
* 이전 회차 값을 참고로 보여줄 땐 `⬜ 미정 (지난번엔 OOO)` 형태
* 셰프 확인이 필요한 Claude의 제안은 `(제안)` 으로 표시
* 계량·부위 등 정확한 수치는 "정확한 계량 후 안내"로 두고 셰프 확인 목록에 올림
* 대사 예시는 조서형 셰프 말투: 존댓말, 따뜻하고 친근한 구어체, "오늘의 치트키를 시작해 보겠습니다" 같은 고정 멘트
* 오프닝 고정 인사: "안녕하세요. 풍류천재 조서형입니다."
* PD 질문은 시청자 눈높이, 따라 하다 막히는 지점 위주 (왜 그래요? 언제 넣어요? 대체 재료는? 보관은?)
* 지역 음식이면 지역 비교 질문 포함 (예: 서울식 vs 경상도식)
* 재료 소개 파트에 대체 재료 꼭 언급

## 4. 기획안 템플릿 구조 (치트키 기준)

→ `corners/치트키.yaml` 과 `planner/schema.py` 로 옮겨 구현함.

## 5. 참고 — 고정값

* 채널명: 풍류천재조서형 / 담당 PD: 정해빈
* 직전 회차 참고값: 촬영감독 임태성 감독님, 촬영 장소 조서형님 자택 (회차마다 확인 필요)

→ 채널 고정값은 `profiles/pungnyu.yaml`, 코너별 지난 회차 값은 `corners/<코너>.yaml` 의 previous_values 로 옮겨 구현함.

## 6. 구현 아이디어 → 현재 상태

1. 템플릿을 구조화 데이터로 정의 — ✅ `schema.py`(Pydantic) + `corners/*.yaml`
2. 입력 → Claude API → 스키마에 맞는 JSON — ✅ `generate.py` (structured outputs)
3. JSON → 텍스트 렌더링 — ✅ `render.py`. 결과는 회사 내부 기획안 플랫폼에 PD가 옮겨 적으므로 디자인 출력(HTML/PDF)은 만들지 않음
4. 레퍼런스 PDF/이미지 업로드 — ✅ PDF를 그대로 document 블록으로 전달(이미지형 PDF도 페이지를 시각적으로 읽음), PNG/JPG도 가능
5. 코너별 템플릿 분리 — ✅ 치트키 / 풍류유람기 / 마감주 yaml (실제 기획안 PDF 3개 기준)
6. 완성본 아카이브 → 다음 회차 레퍼런스 — ✅ `archive/` 저장 + `--ref archive/.../plan.json`

## 7. 아직 정해야 할 것

* 실행 형태: 현재 로컬 CLI (Claude API 키 필요). Claude 앱 스킬로 옮기는 것도 고려
* 최종 출력: 텍스트(plan.md) — 회사 기획안 플랫폼에 옮겨 적음 (결정됨)
